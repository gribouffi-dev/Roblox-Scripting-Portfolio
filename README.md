## Projects

### Cuff System
A multiplayer cuff system allowing officers to:
- Cuff players
- Drag detained players
- Jail players for a selected duration
- Release players

### Inventory System
A persistent inventory system allowing players to:
- Store items
- Drop items
- Pick items up
- Keep their inventory after leaving the game

### Squad System
A multiplayer squad system featuring:
- Player invitations
- Squad leaving
- Squad leader
- GPS markers above squad members

### Guided Missile
A remotely controlled missile system featuring:
- Player-controlled missile
- Camera following the missile
- Mouse-based steering
- Explosion and damage system
